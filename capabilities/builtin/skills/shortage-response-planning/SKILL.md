# 缺料响应 Path 规划

根据当前 Case 事实和 HumanProposal 评估本 Skill 包 `paths.json` 声明的每一条 Path。每条 Path 必须恰好返回一次，可以排序并用中文解释，但不得遗漏或发明 Path。由 Owner 在 Manifest 评审时决定哪些 Path 进入探索。

对每条 Path，用中文说明哪些当前 Case 事实使其相关。不得把历史 Knowledge 当作当前证据，不得批准 Path、作出业务承诺，或修改 ERP、库存、订单、供应商、物流、CRM 与客户系统。
