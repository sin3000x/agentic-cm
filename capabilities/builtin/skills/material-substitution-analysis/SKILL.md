# 物料替代分析

1. 仅依据 `authorized_options` 与 `tool_results` 形成一份中文推荐方案，不得发明未授权候选或写成已确认承诺。
2. 使用 Bundle 内三个专业分析 Skill，分别比较技术、供应与交付、客户与商务接受度。
3. `human_proposal` 只提供目标偏好，Knowledge 只提供历史背景，两者都不能替代当前证据或责任角色确认。
4. 为 `required_role_reports` 中每个契约写一条报告，说明为何这份推荐方案应在该维度被批准，以及仍待该角色确认的事项。
