# 候选料供应覆盖与交期分析

1. 从 `/case/snapshot.json` 读取缺料编码与缺口数量，并从 `lookup_material_substitutes` 的结果取得候选的实际 `material_id`；尚未查询时先按 Case 缺料编码查询替代关系。
2. 对每个查得的候选调用 `lookup_supply_snapshot(material_id)`，取得冻结的库存、调拨与补货记录。
3. 计算并比较现货覆盖、剩余缺口、调拨周期、补量需求和补量周期。需要的是“某个替代料在某个截止日期前可供货的数量”，不能把当前库存或历史补货周期当作该日期的供货确认。
4. 当 Case 或工具资料未能确认该数量时，向主计划提出信息请求，写明实际候选料号 `material_id` 和 Case 交付约束日期 `required_by`；要求提供可供货数量与供应来源、到货日期、确认依据。不要把这一步当作批准整个替代方案。
5. 人工回答后按对应料号与截止日期比较其可供数量和订单缺口，明确剩余缺口，再生成待审批方案。供应与交付报告须保留来源和仍未确认的条件。冻结快照不代表锁定库存、排产或交付承诺。

查询未返回记录时标为证据缺失，不得把无记录解释为不允许查询，也不得编造替代关系或事实。
