# 检查地区认证

1. 读取 Manifest 已批准的候选物料、目标客户和销售地区。
2. 分别列出每个候选物料已确认的认证、缺失证据和待核实事项。
3. 引用 Knowledge 时保留来源，不把历史观察当作当前认证事实。
4. 输出结构化检查结果，并将缺少当前证据的项目交给合规责任人确认。

不得自行扩大候选物料范围，不得替合规人员签署承诺，不得修改产品、订单或客户系统。
